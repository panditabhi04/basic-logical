Authentication :-

Node.js authentication means verifying the identity of a user during the login process. There are two common methods: Session-based Authentication and Token-based Authentication (using JWT).
Session-based Authentication :- Stores login info on the server 
Token-based Authentication :- After login, the server sends a JWT token to the client and client store it in local storage or cookies.

JWT:-
JWT (JSON Web Tokens), is a popular and secure method for implementing authentication and authorization in Node.js applications.separated by dots (.). A JWT is dived in of three parts:
Header → Stores the algorithm and token type.
Payload → Stores the actual data (user information/claims).
Signature → Verifies that the token is authentic and not modified.

Aggregate 
Update:-
// Update a single document
db.collectionName.updateOne({ name: "John" }, { $set: { age: 31 } });

// Update multiple documents
db.collectionName.updateMany({ age: { $lt: 30 } }, { $set: { status: "young" } });

// Replace a document
db.collectionName.replaceOne({ name: "John" }, { name: "John", age: 31, status: "updated" });

Delete:-
// Delete a single document
db.collectionName.deleteOne({ name: "John" });

// Delete multiple documents
db.collectionName.deleteMany({ status: "inactive" });
